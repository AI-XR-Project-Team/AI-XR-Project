# UI 목업 대비 현황

실기기(SM-S936N)에서 캡처한 현재 화면과 디자인 목업의 차이를 항목별로 정리한다.
`inbox/ref_map_screen.png`, `inbox/ref_ar_scan_states.png` 가 목표다.

**결론부터: 두 화면 모두 이미 동작한다. 남은 것은 대부분 스타일과 에셋이다.**
구조를 새로 짤 필요가 없다.

처리 주체는 셋으로 나뉜다.

- **C++** — Claude 가 코드로 바꾼다. 에디터 작업 불필요.
- **에셋** — GPT 가 그리고 Claude 가 임포트한다.
- **WBP** — 에디터에서 위젯을 새로 놓아야 한다. Claude 는 못 한다.

## 1. 전체 지도 (WBP_NavMinimapFull + NavFullMapWidget)

우상단 미니맵을 누르면 열린다. 층 도면, POI 마름모 6개, 하단 목적지 버튼
2x3 그리드가 이미 서버 데이터로 채워져 정상 동작한다.

목적지 버튼과 POI 마커는 **C++ 이 런타임에 생성한다**
(`NavFullMapWidget::BuildDestinationButtons`). WBP 에는 컨테이너만 있으면 되고,
없으면 루트에 직접 붙는다. 그래서 스타일 변경이 전부 코드 쪽이다.

| 항목 | 현재 | 목업 | 주체 |
|---|---|---|---|
| 층 도면 | 회색 선 윤곽 | 아이소메트릭 3D 렌더(조명·전시대·화석) | 에셋 |
| 배경 | 불투명 회색 | 박물관 사진 위 어두운 반투명 | 에셋 + C++ |
| POI 마커 | 아이콘만 | 아이콘 + 이름 라벨 + 발광 점 | C++ |
| 목적지 버튼 | 흰 배경, 검은 글씨 | 어두운 배경, 흰 글씨, `>` 셰브론 | C++ |
| 상단 안내 | 회색 박스 텍스트 | 렉시 캐릭터 + 말풍선 | 에셋 + WBP |
| 층 선택기(1F) | 없음 | 우상단 | WBP |
| 나침반 | 없음 | 우상단 | 에셋 + WBP |

버튼 스타일은 `NavFullMapWidget.cpp:127` 부근에 하드코딩돼 있다.
`FSlateRoundedBoxBrush(FLinearColor::White, 14, Accent, 7)` 와 라벨 색
`(0.10, 0.10, 0.11)` 을 바꾸면 된다.

마커 라벨은 `UNavDestMarkerWidget::SetDestination(MapXY, NodeType, InLabel)` 로
이미 넘어온다. 표시만 켜면 된다.

## 2. AR 스캔 (WBP_DocentChat 위에 얹힘)

`WBP_DocentChat` 이 실질적인 메인 HUD 다. 하단 탭바(`BottomBar`)와
AR 닫기 버튼(`Btn_CloseAR`)이 여기 붙어 있다.

측위 전에는 내비게이션 탭과 AR 스캔 탭이 같은 화면
("바닥의 마커를 인식시켜주세요")을 보여 준다.

| 항목 | 현재 | 목업 | 주체 |
|---|---|---|---|
| 코너 브래킷 | 흰색 고정 | 상태별 색(파랑 -> 초록) | C++ + 에셋 |
| 힌트 문구 | 회색 박스 1종 | 렉시 말풍선 3상태 | C++ + 에셋 + WBP |
| 위치 칩(좌상단) | 없음 | "전시존 / 현재 위치 ●" | WBP |
| 미니맵(우상단) | 회색 사각형 | 원형, 현재 위치 점 | 에셋 + C++ |
| 카메라 컨트롤 | 없음 | 갤러리 / 셔터 / 전환 / 플래시 | 에셋 + WBP |
| 탭바 | 있음 | 동일 | - |

힌트 3상태는 목업 기준 이렇다.

1. 탐색 중 — 브래킷 흰색, 문구 없음
2. 조준 — 브래킷 파랑, "공룡을 화면 중앙에 맞춰주세요 / 더 선명하게 인식할 수 있어요!"
3. 인식됨 — 브래킷 초록, "대상을 인식했어요! / 화면을 터치하면 정보를 볼 수 있어요."
