### 결과물 성격 구분 (중요)

GPT 가 주는 이미지는 두 종류이고 쓰임이 다르다.

- **바로 쓰는 것** — 앱 아이콘, 개별 스프라이트(마커 아이콘, 버튼 배경, 탭바
  아이콘). 투명 배경 PNG 로 낱장이면 그대로 프로젝트에 넣는다.
- **참고만 되는 것** — 화면 전체 목업. 이건 앱에 넣을 수 없다. UMG 위젯으로
  다시 만들어야 한다. 목업 한 장을 통째로 화면에 깔면 버튼도 안 눌리고
  해상도도 안 맞는다.

목업만 받으면 구현 근거로만 쓰이고, 실제 작업량은 줄지 않는다. 화면에 넣을
그림이 필요하면 **낱장 스프라이트**로 따로 요청해야 한다.

## REQ-001 — 앱 런처 아이콘

**상태: OPEN**
요청자: Claude / 등록: 2026-09-10

### 배경

지금 폰 런처에 언리얼 기본 'U' 로고가 뜬다. 커밋 `6b51c29` 가
"앱 아이콘 설정" 이라고 되어 있지만 실제로는 `ApplicationDisplayName`
(앱 이름) 만 넣었고 이미지 파일은 한 장도 없다. `Build/Android/res/`
폴더 자체가 없어서 엔진 기본 아이콘이 그대로 패키징된다.

### 필요한 것

`docs/ai-handoff/inbox/` 에 아래 두 파일을 **이 이름 그대로** 저장한다.

| 파일명 | 크기 | 배경 | 용도 |
|---|---|---|---|
| `icon_master.png` | 1024x1024 | 불투명(꽉 참) | 레거시 런처 아이콘 |
| `icon_foreground.png` | 1024x1024 | 투명 | 적응형 아이콘 전경 레이어 |

그리고 적응형 아이콘 배경색 16진수 값 하나 (예: `#0B1E3D`).

두 장이 필요한 이유: 안드로이드 8 이상은 적응형 아이콘을 쓴다. 전경/배경
레이어가 없으면 삼성 런처가 흰 원 안에 이미지를 우겨넣어 지저분해진다.
갤럭시 S25 에서 쓸 것이므로 둘 다 필요하다.

해상도별(36~192px) 리사이즈는 Claude 가 스크립트로 처리한다.
GPT 에게 여러 크기를 요구하지 않는다.

### [GPT 프롬프트]

아래 블록을 통째로 ChatGPT 에 붙여넣는다. 레퍼런스 이미지가 있다면
같이 첨부한다.

```
공룡 박물관 AR 앱 "TimeMachineAR" 의 안드로이드 런처 아이콘을 만들어 주세요.

[캐릭터]
앱의 마스코트는 AI 도슨트 '렉시' 입니다. 첨부한 레퍼런스를 따르되,
핵심 특징은 이렇습니다.
- 둥근 흰색 헬멧을 쓴 귀여운 로봇 얼굴
- 검은 바이저 안에 밝은 청록색(cyan) 눈 두 개, 부드럽게 빛남
- 양옆에 흰색 헤드폰
- 머리 위 가느다란 안테나, 끝에 빛나는 구슬
- 전체적으로 파란색 글로우, 매끈한 유광 재질

[스타일]
- 3D 렌더링 느낌의 깔끔한 마스코트 아이콘
- 정면을 보는 얼굴 클로즈업
- 배경은 짙은 남색 계열 그라데이션
- 48픽셀로 줄여도 알아볼 수 있게 단순하고 대비가 강할 것

[반드시 지킬 것]
- 글자, 문자, 숫자를 절대 넣지 말 것
- 정확한 정사각형, 1024 x 1024 픽셀, PNG
- 모서리를 둥글게 깎지 말 것 (런처가 알아서 마스크를 씌움)
- 테두리 액자나 워터마크 없음
- 캔버스 밖으로 나가는 그림자 없음

[결과물 2개]
1) icon_master.png
   - 1024x1024, 불투명 배경
   - 그림이 캔버스를 가장자리까지 꽉 채울 것

2) icon_foreground.png
   - 1024x1024, 배경 완전 투명 (알파 채널)
   - 렉시 캐릭터만, 배경 없이
   - 캐릭터가 중앙 66% 영역(약 676x676) 안에 들어올 것.
     바깥 17% 는 런처가 잘라내는 영역이라 비어 있어야 함

3) 배경 레이어로 쓸 단색 16진수 값 하나를 알려줄 것

[마지막에 아래 형식으로 답할 것]
```
