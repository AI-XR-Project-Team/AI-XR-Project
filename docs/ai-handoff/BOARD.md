### 결과물 성격 구분 (중요)

GPT 가 주는 이미지는 두 종류이고 쓰임이 다르다.

- **바로 쓰는 것** — 앱 아이콘, 개별 스프라이트(마커 아이콘, 버튼 배경, 탭바
  아이콘). 투명 배경 PNG 로 낱장이면 그대로 프로젝트에 넣는다.
- **참고만 되는 것** — 화면 전체 목업. 이건 앱에 넣을 수 없다. UMG 위젯으로
  다시 만들어야 한다. 목업 한 장을 통째로 화면에 깔면 버튼도 안 눌리고
  해상도도 안 맞는다.

목업만 받으면 구현 근거로만 쓰이고, 실제 작업량은 줄지 않는다. 화면에 넣을
그림이 필요하면 **낱장 스프라이트**로 따로 요청해야 한다.

## REQ-002 — 화면 스타일 개선용 에셋

### GPT 가 아니라 Material Symbols 에서 받을 것

기존 아이콘들(`navigation`, `photo_camera`, `refresh`, `chevron_right`,
`menu_book`, `travel_explore` ...)은 전부 Google Material Symbols 다.
GPT 에 그리게 하면 선 두께와 모서리 처리가 달라 한 화면에 섞였을 때 티가 난다.
같은 출처에서 받는 것이 맞다.

<https://fonts.google.com/icons> 에서 아래를 받는다.
설정은 기존 아이콘과 맞춰 **Outlined / Weight 400 / Grade 0 / Optical size 24**,
PNG 512px, 흰색.

| 아이콘 이름 | 쓰임 |
|---|---|
| `photo_library` | 스캔 화면 갤러리 버튼 |
| `flash_on` | 스캔 화면 플래시 버튼 |
| `explore` | 지도 나침반 |
| `expand_less` / `expand_more` | 지도 층 선택기 |

### GPT 에 요청할 것 — 층 도면 배경 (판단 필요)

**먼저 알아야 할 문제가 있다.** 지금 지도는 서버가 준 nav 그래프(벽·노드
좌표)를 C++ 이 실시간으로 그린다. 목업처럼 아이소메트릭 렌더 이미지를 깔려면
그 이미지가 그래프 좌표계와 픽셀 단위로 맞아야 한다. 안 맞으면 공룡 마커가
벽 위나 허공에 뜬다. GPT 가 그린 그림은 그 정렬을 보장할 수 없다.

두 가지 길이 있다.

- **(a) 벡터 유지, 스타일만 개선** — 배경 이미지를 쓰지 않고 벽 색·두께,
  바닥 채움, 그림자, 조명 느낌을 C++ 에서 조정한다. 정렬 문제가 없고
  층이 늘어나도 그대로 동작한다. 에셋 요청 불필요.
- **(b) 목업 그대로 이미지 배경** — GPT 도면을 깔고 스케일·오프셋을 수동으로
  맞춘다. 맵이나 층이 바뀌면 매번 다시 맞춰야 한다.

**(a) 를 권한다.** 목업의 인상은 대부분 색과 조명에서 오고, 그건 벡터로도
상당히 재현된다. (b) 로 가려면 그때 REQ-003 으로 따로 연다.

## REQ-001 — 앱 런처 아이콘

**상태: OPEN**
요청자: Claude / 등록: 2026-09-10

### 배경

지금 폰 런처에 언리얼 기본 'U' 로고가 뜬다. 커밋 `6b51c29` 가
"앱 아이콘 설정" 이라고 되어 있지만 실제로는 `ApplicationDisplayName`
(앱 이름) 만 넣었고 이미지 파일은 한 장도 없다. `Build/Android/res/`
폴더 자체가 없어서 엔진 기본 아이콘이 그대로 패키징된다.

### 필요한 것

`docs/ai-handoff/inbox/` 에 아래 두 파일을 **이 이름 그대로** 저장한다.

| 파일명 | 크기 | 배경 | 용도 |
|---|---|---|---|
| `icon_master.png` | 1024x1024 | 불투명(꽉 참) | 레거시 런처 아이콘 |
| `icon_foreground.png` | 1024x1024 | 투명 | 적응형 아이콘 전경 레이어 |

그리고 적응형 아이콘 배경색 16진수 값 하나 (예: `#0B1E3D`).

두 장이 필요한 이유: 안드로이드 8 이상은 적응형 아이콘을 쓴다. 전경/배경
레이어가 없으면 삼성 런처가 흰 원 안에 이미지를 우겨넣어 지저분해진다.
갤럭시 S25 에서 쓸 것이므로 둘 다 필요하다.

해상도별(36~192px) 리사이즈는 Claude 가 스크립트로 처리한다.
GPT 에게 여러 크기를 요구하지 않는다.
