# AR 스캔 화면 목업 분해

원본은 폰 화면 3장을 가로로 붙인 1536x1024 합성 이미지다. 512px 씩 균등
분할하면 패널 하나가 512x1024 로 정확히 떨어진다.

## 앞선 시트와 다른 점 — 이건 스프라이트가 아니다

`inbox/sheet/` 는 배경이 투명한 에셋 시트였다. 이건 **사진 위에 UI 를 합성한
목업 스크린샷**이고 알파 채널이 없다(24bpp RGB). 그래서 UI 만 깨끗하게
떼어낼 수 없다. `parts/` 의 조각들은 전부 배경 사진이 같이 담겨 있다.

**production 에셋으로 쓸 수 없다. 치수·색·배치를 재는 참고용이다.**

실제로 넣을 그림은 둘 중 하나다.

- 투명 배경으로 새로 받는다 (BOARD.md REQ-003)
- 코드/머티리얼로 그린다. 브래킷·조준원·셔터링·원형 버튼은 전부 단순 도형이라
  이쪽이 더 깨끗하고 상태별 색 전환도 쉽다

## 상태별 차이

| | 탐색 중 | 조준 | 인식됨 |
|---|---|---|---|
| 패널 | `state1_searching` | `state2_aiming` | `state3_recognized` |
| 코너 브래킷 | 흰색, 글로우 없음 | 파랑 + 글로우 | 초록 + 글로우 |
| 중앙 조준원 | 없음 | 있음 | 없음 |
| 렉시 말풍선 | 없음 | 파랑 | 초록 |
| 좌상단 | 뒤로가기 | 햄버거 | 햄버거 |
| 우상단 | 미니맵 | 미니맵 | 새로고침 + 미니맵 |
| 카메라 컨트롤 | 플래시 · 셔터 · 전환 | 갤러리 · 셔터 · 전환 | 갤러리 · 셔터 · 플래시 |
| 대상 표시 | 파란 점들이 흩어짐 | 없음 | 초록 점 1개가 대상에 붙음 |

카메라 컨트롤 구성이 상태마다 다른 것은 목업의 실수로 보인다. 구현할 때는
셋 다 같은 구성(갤러리 · 셔터 · 전환)으로 두고 플래시는 따로 두는 편이 낫다.

## 배치 (패널 512x1024 기준, 괄호는 화면 대비 비율)

| 요소 | x | y | 크기 |
|---|---|---|---|
| 좌상단 버튼 | 20 (3.9%) | 44 (4.3%) | 60x60 |
| 위치 칩 | 84 (16.4%) | 42 (4.1%) | 254x70 |
| 미니맵 | 384 (75%) | 40 (3.9%) | 108 지름 |
| 브래킷 영역 | 76~440 (14.8~86%) | 288~618 (28~60%) | 코너당 약 32x32 |
| 중앙 조준원 | 256 중심 (50%) | 450 중심 (44%) | 약 56 지름 |
| 말풍선 | 32 (6.3%) | 698 (68%) | 450x94 |
| 셔터 | 253 중심 (49%) | 852 중심 (83%) | 약 80 지름 |
| 좌우 컨트롤 | 135 / 371 (26% / 72%) | 852 중심 | 약 56 지름 |
| 탭바 | 12 (2.3%) | 908 (88.7%) | 488x96 |

목업은 1:2 비율인데 실기기(1440x3120)는 1:2.167 이다. 세로 비율을 그대로
쓰면 어긋나므로, 상단·하단은 화면 가장자리 기준으로 앵커를 잡고 가운데는
비율로 두는 편이 맞다.

## 측정한 색

사진 위 합성이라 반투명 요소는 배경과 섞인 값이다. 단색 요소만 신뢰할 수 있다.

| 요소 | 값 | 비고 |
|---|---|---|
| 탭바 활성 텍스트 | `#4C99E2` | 신뢰 가능 |
| 셔터 링 | `#FCFCFB` | 신뢰 가능 |
| 말풍선 테두리(파랑) | `#496D9E` | 신뢰 가능 |
| 말풍선 배경(조준) | `#1D2439` | 배경과 섞임 |
| 탭바 배경 | `#252421` | 배경과 섞임 |
| 원형 버튼 배경 | `#38332D` | 배경과 섞임 |

브래킷 선은 폭이 2~3px 이라 샘플링이 빗나갔다. 눈으로 보면 조준은 밝은
하늘색, 인식은 밝은 연두색이고 둘 다 바깥으로 글로우가 번진다.
