# 사용 순서

1. OPUS_START_KO.md 내용을 Opus에게 전달한다. IMPLEMENTATION_GUIDE_KO.md와 references 이미지를 함께 읽게 한다.
2. Opus가 실제 에셋 조사와 design.md를 만든 뒤, SONNET_TASK_KO.md에 Opus가 지정한 이번 작업 범위를 붙여 Sonnet에 전달한다.
3. Sonnet의 결과와 handoff.md를 Opus에게 돌려주어 통합·Niagara 미술 조정·휴대폰 검수를 진행한다.

품질 우선 권장: Opus가 전체 통합 책임을 계속 보유하고 Sonnet은 확정된 단위 작업을 맡는다. Opus도 실제 에디터/기기 검증 없이 이미지와 같은 품질을 보장할 수 없다.

이번 산출물은 구현 지침서뿐이다. 게임 코드·원본 FBX·Niagara를 수정하거나 패키징하지 않았다.
입력 에셋은 기존 프로젝트 경로를 사용하며 이 폴더에 대용량 원본을 중복 복사하지 않았다.
