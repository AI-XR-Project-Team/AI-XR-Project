# Sonnet에게 전달할 프롬프트

C:/AI-XR-Project/docs/clock-reveal-handoff/IMPLEMENTATION_GUIDE_KO.md와 Opus가 작성한 design.md, handoff.md를 읽어 주세요. 당신은 확정된 설계의 개별 구현을 담당합니다. 설계 문서가 없으면 전체 AR 통합을 추측해서 만들지 말고, 독립적으로 가능한 시계 에셋 조사·임포트 준비부터 수행하고 미정 API를 보고하세요.

이번 작업은 다음 항목 중 Opus가 지정한 하나씩 수행합니다.

1. 시계 원본 3개를 보존하며 모바일용 임포트 스크립트, 파생 메시/재질, 본체+짧은 바늘+긴 바늘 조립 Actor를 만듭니다. 바늘은 문자판 중앙 피벗에서 회전하며 관통·중복 바늘·z-fighting이 없어야 합니다. 실제 삼각형 수·텍스처 크기·재질 수와 검수 이미지를 보고합니다. 원본 4K와 무거운 메시를 무조건 그대로 패키징하지 않습니다.
2. 확정 API에 맞춰 상태 전이·포물선 궤적·터치 판정·취소·중복 방지·폴백을 구현합니다. 기존 응시 등장/정보창 터치/StopScan과의 연결은 Opus가 지정한 범위만 변경합니다. 정상 완료와 취소 후 입력 복구를 테스트합니다.
3. Opus 검수에서 지정한 수치 조정, cook 포함 검증, 테스트·패키징 작업을 수행합니다. 테스트 실패를 숨기거나 검증하지 않은 실기기 성공을 보고하지 않습니다.

공통 제약: 기존 UI/도슨트/정보창을 다시 만들지 않습니다. Niagara 원본·공유 원본 재질은 수정하지 않습니다. User 파라미터는 실제 그래프에서 소비되는지 검증해야 합니다. 모든 변경 파일, 실행한 검증, 미해결 항목을 handoff.md에 기록하고 다음 검수 담당자가 재현할 수 있게 하세요. 지정 범위를 넘어 구조 변경이 필요하면 원인과 최소 변경안을 Opus에게 전달하세요.
